# Проверка исходного набора

Архив и извлечённые видео хранятся только локально. Каталог `data/` исключён из Git и Docker-образа. Таблица `open_labels.xlsx` содержит для каждого видео только общий вердикт и секунду события; типа нарушения в ней нет.

Проверка архива:

```bash
python scripts/audit_dataset.py --archive /path/to/open.zip
```

Скрипт проверяет целостность архива, соответствие файлов и меток, длительность, возможность прочитать кадры в начале, середине, конце и у отмеченного события, а также точные дубликаты. Отчёт сохраняется в `data/dataset_audit.json` и не попадает в репозиторий.

Проверенный набор: 42 ролика, 22 с меткой нарушения и 20 без неё. Все ролики — 464 × 848 пикселей; длительность от 11,633 до 142,533 секунды, максимальный размер 28 718 927 байт. Все контрольные кадры прочитались.

Найдены точные дубликаты `Х-4`/`Х-47` и `Х-5`/`Х-48`. У первой пары одинаковые байты, но метки указывают разные секунды — 57 и 68. Возможно, в записи два эпизода; таблица этого не объясняет. Для обучения и проверки дубликаты нельзя распределять по разным выборкам. При оценке точности нужно показывать как результат по всем строкам, так и результат без точных дубликатов.

После подключения модели выполните локальный прогон API:

```bash
API_KEY=<ключ> python scripts/evaluate_api.py
```

В PowerShell задайте ключ как `$env:API_KEY = "<ключ>"`, затем запустите `python scripts/evaluate_api.py`. Для проверки очереди можно добавить `--concurrency 2` или больше на том же оборудовании, где будет проходить демонстрация. Скрипт сохраняет в `data/evaluation.json` вердикты, времена, ошибки обработки, проверку схемы ответа и расстояние от предсказанного таймкода до метки. Кадры и исходные видео в отчёт не записываются. Метрики классификации типа события и смысловую релевантность кадра нужно проверить вручную: исходная таблица их не размечает.

Отложенный набор следует формировать по группам похожих сценариев и точных дубликатов. Проверку под другим углом из текущего набора провести нельзя: все предоставленные видео сняты с одного ракурса. Для этого нужен отдельный ролик с новой камеры.
