# Контракт локального анализатора

Укажите `ANALYZER_ENTRYPOINT=имя.модуля:имя_функции`. Модуль должен быть доступен Python в контейнере и не должен обращаться к облачным AI-сервисам. Функция вызывается в отдельном процессе для каждого видео и получает `pathlib.Path` к загруженному `.mov`.

```python
from pathlib import Path

def analyze_video(video_path: Path) -> list[dict]:
    return [
        {
            "rule_id": "cash_receipt_client_present",
            "timecode_sec": 44.2,
            "observation": "Кассир пересчитывает наличные, когда клиент не виден в полностью обозреваемой клиентской зоне.",
            "evidence_timestamps_sec": [43.8, 44.2, 44.8],
        }
    ]
```

Возвращайте `[]`, только если анализ действительно завершился и уверенных событий не найдено. При ошибке бросайте исключение. Не возвращайте готовые кадры: сервис извлечёт 1–3 JPEG по указанным временам. `rule_id` должен существовать в `app/rules.json`; источник и тип берутся оттуда, чтобы модель не придумывала нормативные ссылки. `observation` описывает только видимое на записи действие. Сервис добавит название документа и пункт в `description` для API жюри.

Для нового типа события сначала добавьте правило в `app/rules.json`: `id`, `title`, `document`, `section`, `url`, `visibility_note`. Проверьте, что правило действует и что его условия можно увидеть в доступном ракурсе. Правила в репозитории — начальные кандидаты, а не утверждение, что такие события есть в датасете.

Таймкоды — секунды от начала видео. Времена кадров должны находиться в пределах 15 секунд от события и внутри видео. Возвращайте только события с проверяемыми кадрами. Если обзор недостаточен или роль человека нельзя установить, не делайте категоричный вывод из отсутствия человека в кадре. Идентификация лиц и анализ звука запрещены условиями кейса.
