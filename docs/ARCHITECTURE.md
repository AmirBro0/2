# Архитектура и границы решения

```text
Браузер / API жюри
        |
        v
FastAPI: ключ, загрузка .mov, выдача статуса
        |
        v
SQLite: очередь и результаты
        |
        v
Локальный процесс анализа -> адаптер модели -> события и времена
        |
        v
Проверка rule_id и времён -> JPEG-кадры -> JSON результата
```

`POST /api/v1/analyze` сохраняет файл локально и возвращает `job_id`. `GET /api/v1/jobs/{job_id}` возвращает `processing`, `done` или `failed`. Модель работает в отдельном процессе, ограниченном по времени. Исходный ролик удаляется после обработки; результат с кадрами удаляется по `RESULT_TTL_HOURS` (по умолчанию 24 часа). При перезапуске незавершённые задания снова попадают в очередь, если их файлы доступны.

Веб-страница показывает статус, возможные события, кадры и ссылку на источник. Выбранное видео можно просмотреть в браузере, а нажатие на таймкод перемещает воспроизведение к событию. Превью использует локальный файл браузера и не требует хранить вторую копию на сервере.

Адаптер получает путь к `.mov` и возвращает список наблюдений по [контракту](MODEL_INTEGRATION.md). Сервис проверяет `rule_id`, времена и текст, а нормативный источник подставляет из [реестра](../app/rules.json). Модель и веса должны быть доступны внутри среды исполнения; обработка видео не вызывает облачные AI-сервисы. Сервис не анализирует звук и не идентифицирует лица.

На текущем этапе анализатор ещё не подключён: `/healthz` возвращает `ready: false`, а интерфейс не предлагает начать проверку. Перечень моделей, их лицензий, распознаваемых категорий и измеренная точность заполняются после передачи адаптера коллегой. Кандидаты в реестре не являются заявлением о фактическом распознавании.

Для одного процесса сервера допустим один локальный планировщик очереди. Число процессов анализа задаётся `PARALLEL_JOBS`; увеличение требует замера памяти и времени на целевом оборудовании. База SQLite подходит для небольшого числа заданий хакатона; при переносе на несколько серверов планировщик и хранилище нужно заменить согласованным общим механизмом.
